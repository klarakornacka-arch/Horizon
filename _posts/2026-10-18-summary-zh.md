### [DeepSeek 检索 API 定价每千次 $0.75](https://api-docs.deepseek.com/guides/search/) ⭐️ 7.0/10

DeepSeek 在其 API 文档站发布 search and fetch 指南页面，页面标题标示价格为每 1000 次成功请求 $0.75（来源：https://api-docs.deepseek.com/guides/search/，2026-10-18）。该条目在 Hacker News 上由用户 fagnerbrack 提交，讨论主要围绕它与 Brave、Kagi、Exa 等搜索 API 的价格对比展开。评论区中，thombles 称同等量级在 Brave Search API 约为 $5、Kagi API 约为 $12；vitorsr 表示自己为语义检索与学术索引支付 Exa 的溢价；mjmvisser 认为这类服务之所以存在，是因为 Google 不提供付费搜索 API。nikvdp 则推荐自建 SearXNG 类方案（其本人为作者，属自述），主张免费替代。需要限制说明的是：提供的材料只有标题与评论，没有独立基准测试、延迟、召回质量、限流、配额或“成功请求”判定规则的细节，因此上述第三方价格均属社区说法，未经核实。

**「设计思维」** 从标题措辞可以验证一个计费单位的取舍：按“成功请求”而非“调用次数”计价（来源：https://api-docs.deepseek.com/guides/search/，2026-10-18）。据此可以做的判断（属推断，非原文声明）是：这种单位把失败调用与空结果的成本留在供应侧，让开发者在预算估算时更接近“拿到可用结果才付费”的模型。但原文未给出“成功”的判定标准，也未说明失败请求是否计费上限，所以这一取舍在真实 agent 重试循环中的效果并不确定。此外，材料中没有出现用户研究、原型迭代或设计流程的任何证据，因此无法讨论其方法层面。

**「商业视角」** 可核实的商业信息只有一条：DeepSeek 公布每 1000 次成功请求 $0.75 的检索定价（https://api-docs.deepseek.com/guides/search/，2026-10-18）。围绕它的市场讨论来自社区而非官方：thombles 在评论中给出 Brave 约 $5、Kagi 约 $12 的对照，vitorsr 称自己为语义检索与学术索引支付 Exa 溢价，agentdev001 指向 Artificial Analysis 的搜索 API 成本汇总。若这些社区数字成立，该定价位于明显低端，可能压低 agent 检索层的接入门槛；但材料未提供 SLA、覆盖语料范围、延迟与稳定性数据，因此“低价是否带来更优的单位任务成本”不确定。评论区还有观点认为该市场存在的前提是 Google 不提供付费搜索 API（mjmvisser），这属社区判断，非可核实事实。

**「创作角度」** 角度一，面向 AI 独立开发者与 agent 构建者：做一张“检索层账单卡”，把每千次请求价格换算成“我的 agent 每天跑 N 次检索，一个月要花多少”，核心问题是——在缺少质量基准的情况下，省下的钱会不会被重试与人工校验吃掉。
角度二，面向关注 AI 产品动态的自媒体读者：以“检索 API 出现价格梯度”为切口，梳理官方定价与社区对照数字的差异，核心问题是——当价格差达到数倍时，开发者真正该比较的是哪几个维度（召回质量、语料覆盖、失败计费规则），而材料恰好缺失这些维度。
