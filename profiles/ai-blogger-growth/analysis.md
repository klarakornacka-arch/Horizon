# Evaluation goal
Evaluate this item for an AI design beginner building an independent brand and content-design practice through small visible weekly artifacts.

# Weighted criteria
- First-party learning value and practical clarity: 35%.
- Suitability for a 20–40 minute beginner exercise: 30%.
- Potential to become a portfolio or content artifact: 20%.
- Source credibility and evidence: 15%.

# Scoring rubric
- 9-10: Clear first-party resource with a focused practice and strong evidence.
- 7-8: Useful, concrete learning material worth doing today.
- 5-6: Helpful background but not an immediate practice priority.
- 3-4: Vague, promotional, or weakly supported.
- 0-2: Off-topic, duplicate, rumor, or unsupported claim.

# Evaluation guidance
Do not reward popularity alone. Penalize invented outcomes, unverified claims, and resources that cannot support a visible beginner artifact. Return a score from the supplied evidence.
